# Contributing to Umono

Thanks for your interest in Umono. Please read this page before you put time into a contribution, so none of it is wasted.

## How Umono is developed

- **One developer.** Umono is developed by Yunus Emre Bulut alone. There is no team.
- **The process is private.** Decisions, specs and planning live in a private document. What is public is the code, the README, [docs.umono.dev](https://docs.umono.dev), the issues and the discussions.
- **Built with AI.** The code is written by AI agents. The design, the decisions and the review are the developer's. See [How it's built](README.md#how-its-built) in the README.

## How you can help

The most useful contributions are issues and discussions.

- **Bugs:** open an [issue](https://github.com/umono-cms/umono/issues/new/choose) with the **Bug report** template.
- **Feature ideas:** open an issue with the **Feature request** template, or start a discussion.
- **Feedback and questions:** use [GitHub Discussions](https://github.com/umono-cms/umono/discussions). "I installed it and this confused me" is welcome there.
- **Security vulnerabilities:** do not report them in public. Follow [SECURITY.md](SECURITY.md).

## Writing a theme

Writing a theme is not a code contribution and needs no assignment. The Theme API is public and themes live in their own repositories. Start with [Your first theme](https://docs.umono.dev/themes/your-first-theme/) on docs.umono.dev.

## Code contributions

Umono does not need many code contributions. If you still want to write code:

1. **Work on an assigned task only.** The task must be decided in an issue or a discussion and assigned to you. Deciding and assigning are the developer's call, because decisions are made in the private document and a change that has not been decided may not fit them.
2. **Pull requests for unassigned work are closed without review.** There are no exceptions, typo fixes included. Every change starts as an issue or a discussion.
3. **Declare your AI use.** Using AI is fine. The pull request description says which AI tools you used and what was written with them. Pull requests without this declaration are closed.
4. **Behavior changes come with tests.** This applies to the project's own changes too.
